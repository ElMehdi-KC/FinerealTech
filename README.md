# FinerealTech
​📝 Description du Projet
​Le projet Quiz de Révision - TECH Université est une application web monopage (Single Page Application) légère, responsive et prête à l'emploi. Elle permet aux collaborateurs et futurs spécialistes d'évaluer leurs connaissances sur l'organisation globale de TECH Université, la politique de bourses FUNDEUM, le portefeuille de diplômes et la méthodologie pédagogique Relearning.
